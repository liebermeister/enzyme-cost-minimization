# E. coli central carbon metabolism, variant ccm_aerobic

## Provenance (reconstructed 2026-11-14)

* Variant of the model of Noor et al. (2016): 29 reactions (no PPC), H2O written in 7 reactions, 16 external
  metabolites; reaction and compound tables, layout and plotting order only.
* The SBtab 1.1 example `escherichia-coli_ccm_aerobic_ModelData.tsv` (sbtab-matlab package) contains this network
  with balanced kinetic constants close to, but not identical with, those of `../escherichia-coli_noor_2016`
  (a separate balancing run).
* Full history of all versions: the README of the model collection folder `escherichia-coli-noor-2016` (local model collection of the author).
